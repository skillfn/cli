# Security Policy

Skillfn exists to make AI agent skills more trustworthy — so we take reports about this project's own security seriously.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Instead, email **support@skillfn.com** with:
- A description of the vulnerability and its potential impact.
- Steps to reproduce it (a minimal example is ideal).
- Any suggested fix, if you have one.

We'll acknowledge your report as soon as possible and keep you updated as we investigate and fix it. Once a fix is released, we'll credit you in the release notes unless you'd prefer to stay anonymous.

## Scope

This policy covers the `skillfn` CLI in this repository — the local scanner, the publish/update client, and anything else shipped in this package. For a vulnerability in a specific skill published to the Skillfn Hub, use the report mechanism on that skill's page instead.

## Supported versions

This project is pre-1.0 (`0.x`) — only the latest published version is supported. Please upgrade before reporting an issue that may already be fixed.
